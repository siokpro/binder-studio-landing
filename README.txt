BINDER STUDIO — LANDING V1
==========================

Esta es una primera versión estática para revisión visual y de contenido.

ARCHIVOS
- index.html      Página principal
- styles.css      Diseño responsive
- script.js       Animaciones, selector ES/EN y formulario de demostración
- assets/         Imágenes y vídeo proporcionados

CÓMO VERLA
1. Abre index.html en Chrome/Edge.
2. Para verla exactamente como un sitio web local, desde esta carpeta puedes ejecutar:
   python -m http.server 8000
   y abrir http://localhost:8000

IMPORTANTE SOBRE EL FORMULARIO
El formulario de email está deliberadamente en modo DEMO para esta V1.
No almacena correos todavía. Cuando decidamos el proveedor (por ejemplo Kit),
se conectará al formulario real sin necesidad de rediseñar la página.
